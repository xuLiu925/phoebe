# Phoebe 重建版

> **声明**：本项目是根据公开资料和已知项目线索，重建的“百度知识营销 CPC 业务端”形态的可运行系统，用来近似某内部项目 Phoebe 的业务形态。
> **它不是百度原始源码**，也不包含原项目的接口、数据库结构或代码。所有推断都标注了证据等级，集中记录在 [docs/03-差异与不确定性清单.md](docs/03-差异与不确定性清单.md)。

## 业务闭环

```
广告主建计划（预算/地域/移动出价比例）
  ├─ 建中间页（PC + 无线，分模块编辑 → 全部保存 / 保存并提交）──┐
  └─ 建单元（出价/订阅词）→ 建问答（优质问答/推荐问题/手动/Excel）─┤
                                                               ▼
                               审核台：机器预审（违禁词）+ 人工审核
                                                               ▼
              审核通过的问答 + 审核通过并启用的中间页 → 具备投放资格
                                                               ▼
  投放模拟器：检索 → CPT 包词优先占第一个广告位 → 触发词匹配 → GSP 二价竞拍（CPC 顺延） → 与自然结果混排（第 4 位）
              → 点击问答入口 CPC 扣费 → 进入中间页（内部点击不计费）
                                                               ▼
                              数据报告 / 历史操作记录 / 出价助手
```

## 快速开始

需要 JDK 17+、Maven 3.9+；只有修改前端时才需要 Node 18+。

```powershell
mvn -q install -DskipTests
```

```powershell
java -jar phoebe-web/target/phoebe.jar
```

打开 http://localhost:8080 。默认使用 H2 内存库，每次启动都会重新灌入演示数据。改用 MySQL 和前端开发模式的方法见 [docs/启动指南.md](docs/启动指南.md)。

## 项目结构

```
phoebe-rebuild/
├── phoebe-common/      Result、异常、@Evidence 证据等级注解、文本规则（汉字计2字符、连续标点）
├── phoebe-domain/      实体、Mapper、业务服务（账户/计划/单元/问答/创意/中间页/审核/报表/资源）、PhoebeRules 规则配置
├── phoebe-simulator/   模拟投放：问答知识库推荐、触发词匹配、GSP 竞价、CPC 计费、出价助手、智能引导
├── phoebe-web/         Spring Boot 启动模块：REST 控制器、JWT 安全、SQL 脚本、测试；static/ 为前端构建产物
├── phoebe-ui/          Vue 3 + Element Plus 管理后台源码
└── docs/               设计与交付文档
```
