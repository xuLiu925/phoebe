# 本地启动指南

## 环境
- JDK 17+、Maven 3.9+（必需）
- Node 18+（只有修改前端时需要；仓库里已经包含构建好的前端，位于 `phoebe-web/src/main/resources/static`）
- MySQL 8（可选；默认使用 H2 内存库，不需要安装数据库）

## 方式一：一键运行（H2 内存库）
```powershell
mvn -q install -DskipTests
```
```powershell
java -jar phoebe-web/target/phoebe.jar
```
打开 http://localhost:8080 。每次启动都会重新建表并灌入演示数据，同时生成最近 7 天的模拟统计。

## 方式二：MySQL
1. 建库：
```sql
CREATE DATABASE phoebe DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_general_ci;
```
2. 启动（启动时会自动执行可重复的建表和演示数据脚本）：
```powershell
java -jar phoebe-web/target/phoebe.jar --spring.profiles.active=mysql --MYSQL_USER=root --MYSQL_PASSWORD=你的密码
```
从旧版本升级已有的 MySQL 库时，先执行 `phoebe-web/src/main/resources/db/upgrade-2026-11-25.sql`（执行前备份；脚本可重复执行，已完成的步骤会自动跳过）。已在 MySQL 8.3.0 上验证：旧库升级后列与索引和全新安装完全一致，旧统计数据保留并归入渠道 ZHIDAO、地域“未知”。

也可以用环境变量 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_DB`、`MYSQL_USER`、`MYSQL_PASSWORD` 配置连接。手动建表时直接执行 `phoebe-web/src/main/resources/db/schema.sql` 和 `data.sql`。

## 方式三：前端开发模式
```powershell
java -jar phoebe-web/target/phoebe.jar
```
另开一个终端：
```powershell
cd phoebe-ui; npm install; npm run dev
```
访问 http://localhost:5173 ，`/api` 会代理到 8080。修改完成后执行 `npm run build`，产物会输出到后端的 static 目录。

## 演示数据说明（全部为虚构）
- **青禾美妆**：计划“眼霜知识推广”（预算 300，移动比例 1.2，有一套已启用的有效中间页 A 和一套草稿中间页 B）；计划“面霜知识推广”（没有中间页，用来演示“缺少有效中间页不可投放”）。问答中有审核通过、待审核、审核拒绝三种状态各一条以上；有一个高级创意。
- **悦颜护肤**：在“眼霜什么牌子好？”上与青禾竞价，用来演示二价计费。
- **小树母婴**：宝宝知道渠道的辅食问答。
- 问答知识库有 20 条虚构问题（其中 4 条为带答案的优质问答）。

## 建议体验路径（约 5 分钟）
1. 用 `demo` 登录 → 首页看投放诊断 → “推广管理”里“面霜知识推广”显示“无启用且审核通过的中间页”。
2. 进入“面霜知识推广” → 中间页 tab → 新建 → 导入“眼霜中间页A” → 全部保存并提交。
3. 换 `auditor` 登录 → 审核台通过该中间页 → 换回 `demo`，在计划详情里启用 → 投放诊断变为“有效投放中”。
4. 投放模拟器：分别用 PC 和移动检索“眼霜什么牌子好”，观察移动出价比例 1.2 如何改变胜出者；点击广告看计费和中间页；点击中间页内的按钮，确认不计费。
5. 单元详情：Excel 上传问答（先下载模板）；故意输入“？？”看校验提示。
6. 数据报告：把结束日期选到今天，查看刚产生的点击和消费。
